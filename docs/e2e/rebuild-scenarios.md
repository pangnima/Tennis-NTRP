# 현행 E2E 절차서 (Week 72 재구축 이후)

재구축 전의 절차서(`docs/history/e2e-pre-rebuild/` — 매칭 룸·기록·여정)는 **사라진 흐름**(확인·이의·초대 수락·자동 대진표·로테이션)의 기록이다. 지우지 않고 남겨 두지만 더 이상 돌리지 않는다. 계정·도구 규약은 `README.md`, 계정 생명주기는 `account-scenarios.md`가 그대로 유효하다(착지 경로만 `/home`으로 바뀌었다).

- 서버: 로컬 `npm run dev`(dev DB). 뷰포트 **390×844 먼저**, 그다음 1280.
- 계정: 남자01(`namja01`, 기록 0건)·남자02(`namja02`, 기록 있음)·여자01(기록 0건). 비밀번호 `123123`.
- 태그: 매칭 코트명 `E2E-…`, 매칭 없는 게임 메모 `E2E-…`. 끝나면 `scripts/e2e-cleanup.sql`.
- 표기: ✅ 돌려서 확인 / ◻ 아직 안 돌림(절차만 있음) / SQL = 롤백 스모크로만 확인.
